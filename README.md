# Monik — чистий HTML + CSS (Vite)

Головна сторінка Monik, переписана з експорту Claude Design у звичайний
HTML + CSS + vanilla JS під збірку Vite. Розмітка і стилі розділені, розміри
приведені до дизайн-шкали. Ціль макета — коректний імпорт у Figma плагіном
**html.to.design**: чиста семантична розмітка → чисте дерево шарів.

## Запуск

```bash
npm install
npm run dev       # дев-сервер Vite
npm run build     # прод-збірка у dist/
npm run preview   # перегляд зібраного
```

Точки входу (multi-page): `index.html` (головна) і `styleguide.html` (токени).

> Шрифти (Fixel) підключаються з jsDelivr — потрібен інтернет.

## Шкала розмірів

Базова шкала відступів — сімейство **4 / 8 / 16 / 32 / 64**:
`2 4 8 12 16 24 32 40 48 56 64 80 96 128`.
Правила округлення при знятті з оригіналу:

- `< 16px` → до найближчого кратного **4** (2px — лише хайрлайни / мікровідступи);
- `>= 16px` → до найближчого кратного **8**;
- рівновіддалені → **вниз**.

Окремі шкали:

| Шкала | Значення |
|---|---|
| radius | 2, 4, 8, 12, 16, 24, full (9999) |
| border-width | 1, 2 |
| іконки | 16, 20, 24, 32, 40 |
| висоти контролів | 24, 32, 40, 48, 56 (фіксовані) |
| font-size | 12 14 16 18 20 24 28 32 40 48 56 64 80 + display 96 / 128 |

**Типографіка** без `clamp()`: різні розміри на брейкпоінтах задаються медіазапитами,
кожне значення — зі шкали. `line-height` лягає на 4px-сітку (unitless лише коли
результат цілий). `font-weight` — число з `{400, 500, 600, 700}`.

**Структурні розміри** (ширини контейнерів, `flex-basis`, `min-height`) винесені
в окремі `--layout-*` константи з точними значеннями — їх навмисно не приводили
до шкали (округлення дало б зсув 3–4px без візуальної користі).

## Де токени

- `styles/tokens.css` — усі змінні (`--space-*`, `--radius-*`, `--control-h-*`,
  `--icon-*`, `--color`, `--text-*`, `--layout-*`, motion).
- `styles/typography.css` — переюзабельні класи типографіки (`.text-h1`,
  `.text-body`, …): ставимо в розмітці, а не перевизначаємо розмір у компонентах.
- `styles/reset.css`, `styles/layout.css` — база.
- `styles/components/<name>.css` — по одному файлу на компонент.
- `styles/entry.css` — єдина точка входу, що імпортує все.
- `scripts/*.js` — інтерактив (хедер-меню, скрол-ефекти героя, дрейф блобів,
  слайдери брендів і рецептів). Кожен модуль — no-op, якщо його розмітки немає.

Дивись `styleguide.html` — живі зразки всіх токенів і класів.

## Імпорт у Figma (html.to.design)

1. `npm run build`, потім `npm run preview` (або задеплой `dist/`).
2. У Figma → плагін **html.to.design** → вставити URL сторінки.
3. Плагін читає відрендерений DOM, тож семантичні теги й BEM-класи стають
   іменами фреймів/шарів. Повторювані блоки (`.category`, `.recipe-card`,
   `.brand-card`, `.pill`) мають ідентичну структуру — з них зручно робити
   компоненти.

**Що може втратитись при експорті** (див. також кінець `REPORT` у комітах):
позиційно-абсолютні декоративні елементи (блоби, хвилі-роздільники, точки
заливки CTA), рух блобів (rAF), `filter: drop-shadow` на зображеннях. Це
декор — на структуру шарів не впливає.

## Структура

```
index.html            головна (точка входу)
styleguide.html       токени (точка входу)
scripts/              vanilla JS: main.js + модулі по секціях
styles/               tokens / reset / typography / layout / components
public/assets/        зображення та логотипи
vite.config.js        multi-page конфіг
```

Легасі-концепти (`c04-*.html`, `support.js`) лишаються в корені, але **не**
входять до збірки Vite (вона будує лише `index.html` та `styleguide.html`).
